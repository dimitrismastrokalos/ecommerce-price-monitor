# 🛒 E-Commerce Price & Stock Monitor (Python + Playwright)

A fast, lightweight Python script designed to track product prices, page titles, and stock availability across e-commerce platforms without relying on heavy external dependencies.

---

## 🚀 Lite Version Features

- 🔍 **Automated Product Tracking:** Extracts product titles and page data in seconds.
- 🕒 **Timestamp Logging:** Records exact dates and times for every price check.
- 💾 **CSV Export:** Appends structured historical data directly into `price_log.csv`.
- ⚡ **Lightweight Execution:** Built on Playwright for fast headless browser interaction.

---

## ⚙️ Installation & Usage

1. Clone this repository

git clone [https://github.com/dimitrismastrokalos/ecommerce-price-monitor.git](https://github.com/dimitrismastrokalos/ecommerce-price-monitor.git)
cd ecommerce-price-monitor

2. Install dependencies
pip install -r requirements.txt
playwright install

3. Run the monitor
python main.py
